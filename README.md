## 任务提示词

以下为本题完整的 User Prompt 原文，两次执行必须使用完全相同的文本。

我们要对有序数据做范围更新，同时保证不会与其它范围操作互相干扰。请从零实现一个排序索引与范围锁组件。仓库目前只有一个空的 Maven 工程（pom.xml 只声明 JUnit 5 与 AssertJ）。要求：1) 维护按键有序的索引，支持插入、删除、按键点查与范围查询；2) 支持对指定范围加锁，范围重叠的锁请求必须互斥；3) 锁粒度要合理：不重叠的范围可以并发操作，需有测试证明并行性；4) 支持锁等待与超时，超时时不得留下部分持锁；5) 支持范围更新：在锁保护下批量修改范围内的数据，不得破坏索引顺序；6) 支持锁升级场景：先点锁后扩成范围锁时的行为要明确（允许升级或禁止并报错）；7) 提供统计：当前锁数、等待数、平均持锁时间与范围查询扫描的条数；8) 测试覆盖范围锁互斥、不重叠并行、超时释放、范围更新后索引有序、升级行为与统计；`mvn -q verify` 一条命令跑通。
